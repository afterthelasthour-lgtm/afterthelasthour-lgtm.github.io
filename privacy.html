Privacy policy

ShortsFactory, last updated 7 November 2026

What ShortsFactory is

ShortsFactory is a personal tool. Its only user is the owner of the YouTube channel Wait, What?. It runs on the owner's own computer.

What Google data it uses

With the owner's permission, ShortsFactory uses the YouTube Data API to:

  • upload videos the owner made to the owner's own channel (scope youtube.upload), and
  • read basic information about that channel (scope youtube.readonly).

It does not read, change or delete anything else in the Google account.

Where the data is kept

The sign-in token Google issues is stored only on the owner's computer. ShortsFactory has no server, and no data is sent to anyone other than Google.

Sharing

No data is sold, shared or used for advertising. ShortsFactory's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.
